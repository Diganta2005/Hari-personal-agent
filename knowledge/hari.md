# Hari Knowledge Base

Hari is a personal agent built with Java Spring Boot, HTML, CSS, and JavaScript.

Hari can chat, remember user preferences, save notes, track tasks, perform calculations, accept voice input, speak replies, and show a futuristic UI.

The RAG knowledge folder is used for local retrieval. Add `.txt` or `.md` files here when you want Hari to search your own information.

Example questions:

- search knowledge Hari tools
- search knowledge personal agent
- use knowledge voice assistant
