# 🤖 Hari - Personal Agentic AI

Hari is a personal agentic AI assistant built using Java Spring Boot, HTML, CSS, and JavaScript.

## ✨ Features

- 🤖 Personal AI assistant with chat interface
- 🧠 Agentic behavior for handling user intents
- 💬 Chat-based interaction system
- 🗂️ Chat history saved in the browser
- 🧾 Export chat conversations as text files
- 📋 Notes management system
- ✅ Task management system
- 🧠 Local memory for remembering user information
- 🔍 RAG-based local knowledge search
- 📚 Knowledge base support using `.txt` and `.md` files
- 🧮 Complex calculator tool
- 🎙️ Voice input using browser speech recognition
- 🔊 Spoken replies using text-to-speech
- 🌐 OpenAI API integration
- 🎨 Modern UI/UX design
- 🌀 Futuristic 3D background using Three.js
- 📱 Responsive layout
- 📦 Installable PWA support
- 🐳 Docker support
- 🔐 API key protection using environment variables
